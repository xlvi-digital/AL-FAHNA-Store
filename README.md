AL FAHNA STORE — Solusi Kebutuhan Kang Santri

Website landing page dan katalog toko online resmi untuk AL FAHNA STORE yang menyediakan berbagai kebutuhan kang santri mulai dari kitab, produk herbal HNI, perlengkapan muslim, minyak wangi, hingga alat tulis santri.

Website ini dibangun dengan pendekatan Modern Islamic E-Commerce yang bersih, minimalis, responsif (mobile-first), dan terintegrasi langsung dengan pemesanan via WhatsApp Checkout.

✨ Fitur Utama

Katalog Produk Terintegrasi

Menampilkan daftar produk lengkap dengan nama, kategori, harga jual, harga promo/coret otomatis, serta deskripsi produk yang informatif.

Modal detail produk untuk membaca keterangan produk secara menyeluruh.

Pencarian, Filter Kategori, & Sorting

Kategori produk dihasilkan secara otomatis berdasarkan item yang tersedia di katalog (Kitab Assafany, Produk Hni, Alat Tulis Santri, dll.).

Fitur pencarian berdasarkan nama produk serta pengurutan harga (termurah, tertinggi, dan abjad A–Z).

Keranjang Belanja Interaktif (localStorage)

Tambah/kurangi jumlah item, hapus produk, dan kalkulasi subtotal maupun total pesanan secara real-time.

Data keranjang tersimpan otomatis di browser pelanggan sehingga tidak hilang saat halaman di-refresh.

Checkout Otomatis via WhatsApp

Validasi formulir data pemesan (Nama, Nomor WhatsApp, Alamat Pengiriman, dan Catatan).

Menyusun format pesan pesanan secara otomatis dan mengarahkan langsung ke WhatsApp Admin (6288289533300).

Pengelola Katalog Lokal & Pemisah Kode

Dilengkapi fitur Tambah / Kelola Produk langsung dari antarmuka web serta utilitas penyalinan kode terpisah (style.css & script.js).

🛠️ Teknologi yang Digunakan

HTML5 — Struktur semantik dan SEO dasar

CSS3 & Tailwind CSS (CDN) — Styling kustom nuansa Navy Blue (#0B1F45), Deep Navy (#07152F), Putih (#FFFFFF), dan aksen Gold (#C6A46A)

Vanilla JavaScript (ES6+) — Logika katalog, pencarian, keranjang belanja, dan integrasi WhatsApp tanpa backend maupun framework berat

🚀 Cara Menjalankan & Publikasi (GitHub Pages)

Menjalankan Secara Lokal

Cukup unduh repositori ini dan buka file index.html langsung menggunakan browser (Chrome, Edge, Safari, atau Firefox).

Publikasi Online via GitHub Pages

Buka tab Settings pada repositori GitHub ini.

Pilih menu Pages di bilah sisi kiri.

Pada bagian Build and deployment > Branch, pilih branch main dan folder / (root), lalu klik Save.

Tunggu beberapa saat hingga tautan website aktif di https://xlvi-digital.github.io/AL-FAHNA-Store/.
